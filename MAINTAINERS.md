# Melora Maintainers

This file documents how Melora is maintained. The current maintainer roster is managed through the repository's GitHub permissions so this document does not duplicate stale account or contributor data.

## Responsibilities

Maintainers guide Melora's direction, review contributions, manage releases, and keep project documentation and community spaces current.

## Contact

Use the contact method published on the Melora repository's GitHub page for maintainer and project questions. For contribution proposals, see [CONTRIBUTING.md](CONTRIBUTING.md).
